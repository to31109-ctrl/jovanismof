JOVANISMOF - DEVELOPMENT PLAYTEST
Based on Megabonk Together 5.1.0 by its original contributors.

1. Extract this entire ZIP into its own folder.
2. Double-click Install.cmd and select your Megabonk game folder.
3. Open the new Play JOVANISMOF shortcut. A splash window appears while the mod prepares
   itself. The first launch can take several minutes; leave it alone until the game opens.
4. Select JOVANISMOF, then Friendlies.
5. One player selects Host and shares the room code. Everyone else selects Join.
6. Choose characters, confirm, then let the host start the run.

Use the same package and game version on every computer. Each player needs their
own game installation. This package includes no game files. Send this entire ZIP
to your friend, including its source and license files.

The installer creates a separate BonkLink-Coop game folder. It does not install
BonkWithFriends or load your existing MelonLoader mods. Start the original game
normally for solo play. Recreate the co-op folder after updating the base game.

Shared experience and gold earned are on by default. Purchases spend each
player's own balance. Revive teammates using the coffin/ghost encounter.

The host saves the shared world while you play: every player's items, gold,
level, experience, health, weapons and position, every enemy and boss with its
health, and the run progress. It is written to BonkLink-Coop/BepInEx/BonkLinkWorlds
and never touches your normal single-player save. Host the same stage again and
the run picks up where it stopped; a player who drops out and rejoins gets their
own character back. Settings are under [CoopSaves] in the mod configuration.

The mod uses automatic direct networking with a public relay fallback. No Steam
networking or manual port forwarding is needed. Allow the game network access
if Windows asks. The upstream public service must be reachable by all players.
China-to-South-Africa connectivity and latency have not been tested.

This is a development build, not a completed or stability-certified release.
Read VALIDATION.txt for exactly what was tested and what remains unverified.
If something fails, retain BonkLink-Coop/BepInEx/LogOutput.log from every player.
